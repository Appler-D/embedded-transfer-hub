# 从这里开始

> 先判断你有多少时间，再选路径。不要从第一页读到最后一页才开始动手。

## 路径 A：面试在 7 天内

1. 读 [01 转专业叙事](01-transfer-story.md)：写出你的“为什么转、凭什么转、接下来怎么补”。
2. 读 [04 自动化](04-automation.md)：能白板画出“感知 → 决策 → 执行 → 反馈”。
3. 读 [05 造手机](05-how-a-phone-is-made.md)：能按 6 层讲清手机，不背零件表。
4. 读 [06 面试问答](06-interview-qa.md)：准备 3 个故事 + 25 个问题的回答骨架。
5. 做一个最小项目（[LED + 按钮](../projects/01-led-button/README.md) 或 Wokwi 仿真），留下照片/视频。
6. 录一段 3 分钟 demo：项目是什么、怎么工作、你学到了什么、哪里失败过。

## 路径 B：面试在 1 个月内

- 第 1 周：电子基础 + C + Arduino，完成 LED/按钮/串口。
- 第 2 周：传感器 + OLED，完成“环境监测器”。
- 第 3 周：舵机/继电器/电机，理解 PWM 与供电。
- 第 4 周：ESP32 Wi-Fi + 面试表达 + demo 视频。

详细到周的计划见 [07-learning-path.md](07-learning-path.md)。

## 路径 C：有 12 周

按 [07-learning-path.md](07-learning-path.md) 的 12 周表执行。每周只追一个可展示的产出，不追“看完多少课”。

## 每天 30 分钟怎么用

- 10 分钟：读一个概念，写三句话——它解决什么问题、怎么实现、代价是什么。
- 15 分钟：动手或仿真；哪怕只改一个电阻、一个参数。
- 5 分钟：在 [notes/TEMPLATE.md](../notes/TEMPLATE.md) 记下今天的观察和一句面试讲法。

## 面试前 3 天 checklist

- [ ] 60 秒自我介绍能不看稿说完
- [ ] “为什么转专业”有事实、有动机、有规划
- [ ] “自动化怎么实现”能画图并讲 3 分钟
- [ ] “手机怎么造”能按层次讲 3 分钟
- [ ] 有一个自己真正做过的项目，能讲清失败与修正
- [ ] 准备 2 个反问老师的问题
- [ ] 不会的问题，能用“我目前理解是……我还没学到……我会这样查”回答

## 不要背稿

背稿在追问下会露馅。准备“结构”而不是“句子”：

```text
定义 → 组成 → 例子 → 取舍 → 我的理解 / 不足
```

例如“自动化”：

```text
定义：用系统替代人的感知、判断和执行。
组成：传感器 → 控制器 → 执行器 → 被控对象 → 反馈。
例子：恒温箱、自动分拣、智能家居。
取舍：开环便宜但不可靠；闭环稳定但需要传感器和调参。
我的理解：自动化的核心不是“机器换人”，而是把不确定性收敛到可接受范围。
```

## 记录进度

每完成一项，在 [PROGRESS.md](../PROGRESS.md) 勾掉；每周写一行“做了什么、卡在哪、下周做什么”。这比“看完一门课”更能证明你在往前走。
