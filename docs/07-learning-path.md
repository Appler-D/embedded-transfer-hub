# 学习路线：7 天 / 30 天 / 12 周

> 不要从“看完一门课”开始，从“做出一个能演示的东西”开始。
> 每周只追一个产出：代码、接线图、照片/视频、三句面试讲法。
>
> **如果本轮浙农林转专业在 1–2 个月内**：先看 [12 浙农林转专业攻略](12-zafu-transfer-playbook.md)。GPA 占 70%，先保成绩；同时按 [13 三分钟自述](13-zafu-3min-script.md) 准备面试，做一个 LED+按钮项目，不要开大工程。

## 路线 B：30 天

### 第 1 周：电与代码

- 电压/电流/电阻、欧姆定律、串并联、分压。
- C 基础：变量、`if/for`、函数、数组、结构体、指针（先懂概念）。
- Arduino/ESP32：GPIO、串口、`millis()`。
- 产出：LED 闪烁、按钮控制、串口打印。

### 第 2 周：传感器与显示

- ADC、采样、滤波、I2C。
- 传感器：光敏、温湿度、超声波（任选两个）。
- OLED 显示。
- 产出：环境监测器（传感器 + OLED + 串口）。

### 第 3 周：执行器与供电

- PWM、舵机、继电器、电机驱动。
- 电流、电压跌落、共地、续流、独立供电。
- 产出：舵机扫角 / 风扇调速 / 自动夜灯。

### 第 4 周：联网与表达

- UART、Wi-Fi、HTTP/MQTT（任选）。
- 数据上报到电脑/手机。
- 面试表达：项目 3 分钟、自动化/手机各 3 分钟。
- 产出：能联网的节点 + demo 视频。

## 每周固定动作

- 30 分钟/天：10 分钟读概念，15 分钟动手，5 分钟记笔记。
- 每周日：写一行“本周做了什么、卡在哪、下周做什么”。
- 每完成一个项目：更新 [PROGRESS.md](../PROGRESS.md)，补 3 句面试讲法。

## 没有硬件怎么办

- 用 Wokwi（ESP32/Arduino 仿真）或 Tinkercad Circuits。
- 先仿真通逻辑，再买硬件；不要因为等快递停学。
- 仿真不能替代电源、地、噪声、发热的真实问题；有条件后一定要上手。

## 资料怎么选

- 一门主课 + 一块板子 + 一个项目，够了。
- 不要同时开五门课；不要收藏 100 个视频。
- 看视频超过 20 分钟就停下来动手；看不懂的先记问题，不要死磕。
- 以官方文档和 datasheet 为准；二手教程只用来入门。

## 什么时候算“可以面试”

- [ ] 能用自己的话解释电压/电流、GPIO、ADC、PWM、中断、I2C/SPI。
- [ ] 能画自动化闭环图，并讲一个具体例子。
- [ ] 能按六层讲手机，并说出 2 个取舍。
- [ ] 有一个自己做完的项目，能讲失败与修正。
- [ ] 能诚实说出“我还没学到什么”。
- [ ] 有 2 个反问老师的问题。

## 一句话

> 先做一个能亮、能读、能动的系统，再回头补理论；每补一个概念，就把它放回项目里。
