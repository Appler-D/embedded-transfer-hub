# 浙农林转专业 3 分钟自述逐字稿

> 官方要求（光机电 2026-06-18 通知）：3 分钟中文自我介绍，包含个人及家庭情况、学业基本情况、转专业理由、对专业的理解、相关实践/成绩/获奖、今后学业规划。
> 总面试 5–7 分钟，100 分；综合成绩 = GPA 百分制 ×70% + 面试 ×30%；面试 <60 不录取。
> 不要背成播音腔。记结构，用事实填；目标 2:50，留 10 秒缓冲。

## 时间分配

| 段落 | 时间 | 必须出现的内容 |
| --- | --- | --- |
| 开场 + 个人/家庭 | 0:00–0:20 | 姓名、现专业、家乡/家庭一句 |
| 学业基本情况 | 0:20–0:45 | GPA、排名、优势课程、英语 |
| 转专业理由 | 0:45–1:20 | 具体触发点、可迁移能力、目标吸引点 |
| 对专业的理解 | 1:20–1:55 | 课程、方向、培养方案、你读过什么 |
| 实践/成绩/获奖 | 1:55–2:35 | 一个项目、失败与修正、其他证据 |
| 学业规划 | 2:35–2:55 | 补课、项目、实验室/竞赛、GPA |
| 收尾 | 2:55–3:00 | 一句克制的承诺 |

## 模板（把 `[ ]` 换成你的事实）

### 0:00–0:20 开场 + 个人/家庭

> 各位老师好，我是 `[现专业/班级]` 的 `[姓名]`，来自 `[家乡]`。家里 `[一句带过：普通家庭/支持我读书]`。我今天申请转入电子信息工程。

注意：家庭情况一句带过，不要展开隐私；老师不是在做家访。

### 0:20–0:45 学业基本情况

> 学业上，我目前平均学分绩点 `[X/5]`，专业排名 `[Y/N]`；`[优势课程]` 成绩较好；英语 `[CET-4/6 或目前水平]`。`[如果成绩有波动：大一时……，后来我……]`

注意：诚实。成绩低不要藏，解释趋势和改进；成绩好不要傲慢。

### 0:45–1:20 转专业理由

> 我想转电子信息工程，原因有三点。第一，`[具体经历：一次实验/一个项目/一段自学]` 让我确认了对电路和嵌入式的兴趣。第二，`[原专业训练可迁移：实验设计/测量/数据分析/材料视角]`。第三，`[目标专业的具体吸引点：课程/实验室/方向]`。我不是否定原专业，而是想把已有能力放到更匹配的方向。

注意：说“拉”不说“推”。不要贬低原专业，不要只说“就业好”。

### 1:20–1:55 对专业的理解

> 我理解电子信息工程不是单一方向，至少包括电路与系统、信号与信息处理、通信、嵌入式、控制等。我目前接触最多的是嵌入式：用 MCU 采集传感器、做控制、和上位机通信。我知道要学电路、信号与系统、C 语言、单片机、通信原理等；我也看了培养方案，对 `[课程/实验室/方向]` 特别感兴趣。

注意：提前读一遍 [电子信息工程培养方案](https://gjdxy.zafu.edu.cn/info/1026/1013.htm)，至少记住 2–3 门课和一个方向。不要只说“感兴趣”。

### 1:55–2:35 实践/成绩/获奖

> 我做过 `[项目：LED+按钮 / 传感器+OLED / 小风扇 / 其他]`。它让我理解了 `[GPIO/ADC/I2C/去抖/供电]`。我遇到 `[失败：LED 不亮/读数抖动/舵机掉压]`，后来通过 `[万用表/示波器/查 datasheet/改代码]` 修正。除此之外，我还 `[自学/实验/竞赛/笔记]`。我目前没有 `[大奖]`，但我有 `[真实的过程/代码/记录]`。

注意：没有奖就说没有；老师更想看真实过程。不要编项目。

### 2:35–2:55 学业规划

> 如果转入，我计划：第一，补 `[电路/信号/C 语言/单片机]` 等先修课；第二，每学期做一个项目，逐步做 `[传感器/控制/通信]`；第三，争取进实验室/参加电子设计竞赛；第四，保持 GPA，不让补课拖垮。我知道转专业要补修，我已经做好按培养方案补课的准备。

注意：具体到课程/学期，不要只说“努力学习”。

### 2:55–3:00 收尾

> 谢谢老师。我愿意用接下来的时间证明这个选择不是一时冲动。

## 示例（只学结构，不要照抄）

> 各位老师好，我是来自材料类专业的学生，今天申请转入电子信息工程。
>
> 学业上，我目前平均学分绩点 3.8/5，专业排名前 30%；电路和数学基础较好，英语过了四级。
>
> 我想转专业，是因为我在一次传感器实验里第一次把“物理量—电信号—程序判断—执行器”连了起来，确认自己对嵌入式更感兴趣；材料专业的实验训练也让我习惯测量、排查和数据记录。我了解电子信息工程要学电路、信号与系统、C 语言、单片机、通信和控制；我看过培养方案，对嵌入式方向和单片机课程最感兴趣。
>
> 我做过一个 LED+按钮的小项目，用内部上拉和 20ms 去抖，遇到过 LED 极性接反和读数抖动，后来用万用表和改代码解决。我还没有竞赛奖项，但代码、接线和失败记录都保留了。
>
> 如果转入，我会先补电路、C 语言和单片机，每学期做一个项目，争取进实验室，同时保持 GPA。谢谢老师。

这个示例约 350 字，正常语速约 1 分 40 秒；你需要按自己的事实扩到 2:50 左右。

## 高 GPA 版本（GPA/排名前 5%）

> 我的学业成绩是 `[GPA/排名]`，这说明我有学习能力；但我知道成绩只是门票。我申请转专业不是因为原专业学不好，而是我在 `[具体经历]` 里确认了更想做电子系统。原专业的 `[材料/实验/测量]` 训练能迁移到 `[传感器/可靠性/林业感知装备]`；我已经开始补 `[电路/C/单片机]`，并做了 `[项目]`。我愿意按培养方案补课，不把转专业当成逃避。

要点：

- GPA 一句带过，重点讲“为什么转”和“我做了什么”。
- 不要用成绩压人，也不要说“我随便考考”。
- 准备好“你成绩这么好，为什么转？”和“你原专业不可惜吗？”。

## 如果你确实有材料/工程训练

只有你真实上过/做过才用；没有就跳过。不要写 CAD/CNC/3D 打印如果你没学过。

> 我在原专业上过 `[课程]`，做过 `[实验/项目]`，学到的是 `[测量/记录/排查/数据处理]`；这些习惯能迁移到硬件调试，但我知道电子基础还要补。我目前正在学 `[电路/C/单片机]`，并做了 `[项目]`。

要点：

- 讲“习惯”而不是“精通”。
- 不硬凑原专业和电子的关系；没有连接就不用编。
- 目标专业的平台可以作为“我想去的方向”，但不要声称你参与过。

## 零基础 / 无相关项目版本

> 我目前没有系统的电子项目经验，也没有竞赛奖项。我原来的优势是学习能力：GPA `[X]`，专业排名 `[Y/N]`。我通过 `[自学 C/Arduino/看课程/做 LED 小实验]` 确认了兴趣；我知道自己起步晚，所以计划先补电路、C 语言、单片机，每学期做一个项目，愿意按培养方案补课。我不会把转专业当成逃避，我知道要付出补课成本。

要点：

- 这段适合“没有项目/没有竞赛”的真实情况；不要为了好看编一个。
- 用一个周末做 LED+按钮；这是“已开始行动”的证据，不需要 CAD/CNC。
- GPA/排名是你的强项，但一句带过；重点放在“我在补 + 我愿意补”。

## 无项目 / 无四级版本

> 我目前没有电子项目和竞赛，也没有过四级，这是我的短板。我成绩/排名说明我有学习能力；我已经开始学 C / 做 LED 小项目；我知道要补电路、C、单片机，也会尽快过四级。我不会把转专业当成逃避。

要点：

- 只在你真的开始学/做时说“已经开始”；否则说“我准备从这周开始”。
- 四级没过就诚实说；不要编“已过”。如果已报名，说“已报名，正在准备”。
- 没有项目不是死罪，但“没有任何行动”是；这周就做一个小项目。

## 四门核心课一句话（被问到时）

没学过就说“我看过课程介绍，理解在概念层面”，不要装懂。

- **信号与系统**：研究信号与系统在时域/频域的表示与响应；傅里叶/拉普拉斯、采样、滤波。
- **数字电子技术**：逻辑门、布尔代数、组合/时序逻辑、触发器、状态机。
- **模拟电子技术**：二极管、三极管/MOS、运放、放大与电源电路。
- **C 语言**：变量、控制流、函数、数组、指针、结构体、内存。

## 嵌入式 / 具身智能版本（不暴露私人项目）

> 我对“软件和物理世界结合的系统”感兴趣：传感器、嵌入式控制、人机交互。EE 给我电路、信号、嵌入式的基础；我也会补软件和 AI。我想先把这个方向的基础打牢。

要点：

- 不要提“her”这个名字，也不要说“我要造一个有情感的机器人”；说技术方向。
- 不要说“游戏服务端”除非老师问职业规划；转专业面试的主线是 EE 基础。
- 这是真的：你对具身智能/嵌入式感兴趣，不是编的。

## 目标后端 / 游戏服务端版本

> 我想做软件/系统方向，尤其是大规模在线系统的服务端。CS 转专业今年不开放，EE 是我能转到的最接近的专业：它有 C、数字逻辑、信号、嵌入式，能给我软硬件系统的基础；数据结构、操作系统、网络我会自学/选修补。我知道这是绕路，但我愿意补。我目前电子基础薄弱，已经开始学 C / 做小项目；我也在准备四级。

要点：

- 不要把“CS 不收我”说成怨气；把它说成约束，重点放在“我愿意补 CS 基础”。
- 不要只说“我想去游戏公司”；说“系统/后端/大规模在线服务”，更成熟。
- 也要表现出你愿意学 EE 的硬件课，否则老师会担心你读不下去。
- 长期路线见 [14-game-server-path.md](14-game-server-path.md)。

## 练习方法

1. 先写 700 字左右，不要超过 800 字。
2. 用手机录音，计时；超过 3:00 就删形容词和重复句。
3. 练到 2:50，不看稿，只保留六个段落的顺序。
4. 找同学/朋友模拟老师，随机打断提问；练“被打断后接回来”。
5. 录像看三件事：眼神、语速、口头禅（“然后”“就是”）。
6. 面试前只过结构，不再逐字背。

## 专家可能追问（按段落）

- 你说对嵌入式感兴趣，具体做了什么？为什么用这个传感器？
- 你的 GPA 为什么是这个水平？哪门课拖了后腿？
- 你补课具体怎么排？会不会延毕？
- 你了解我们专业的哪些课程/实验室？
- 你说材料背景有帮助，具体帮助在哪？
- 你还申请了别的专业吗？如果都上了怎么选？
- 如果这次没转成，你怎么办？
- 你最近在读什么？学到什么？
- 你如何看待 AI 对电子信息的影响？
- 你有什么问题问我们？

回答时用“定义 → 组成 → 例子 → 取舍 → 我的理解/不足”；不会就说边界和查证方法。

## 不要说

- “原专业太差了。”——老师会担心你以后也否定这里。
- “我什么都不会，但我会努力。”——只有态度，没有证据。
- “我一定能拿第一。”——过度承诺。
- “我看了很多视频。”——没有动手，说服力弱。
- “我主要是为了就业。”——可以谈现实，但不能只有这一句。
- 编造项目、奖项、成绩——追问三层就露馅。

## 一页纸卡片（面试前只看这个）

```text
六段：个人/家庭 → 学业 → 理由 → 专业理解 → 实践 → 规划
三个数字：GPA、专业排名、项目时长/轮数
一个失败：现象 → 排查 → 根因 → 修正
两个反问：补课安排？实验室准备？
一句收尾：用时间证明不是一时冲动
```

## 最后

3 分钟不是演讲比赛，是让老师确认三件事：你了解目标专业、你有证据、你补得上。把这三件事说清楚，比华丽辞藻重要。
