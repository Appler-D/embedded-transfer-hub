# 电子信息工程课程地图

> 不是让你转专业前学完，而是让你知道“为什么要学、先学什么、面试怎么用”。

## 课程地图

| 课程 | 一句话 | 对嵌入式/通信/微电子 | 先看什么 |
| --- | --- | --- | --- |
| 电路分析 | 电压/电流/功率、节点/网孔、戴维南、RC/RL | 所有硬件的基础 | 欧姆定律、分压、RC |
| 模拟电子 | 二极管、BJT/MOS、运放、放大、电源 | 传感器前端、电源、驱动 | 二极管/三极管开关、运放虚短虚断 |
| 数字电子 | 逻辑门、布尔代数、组合/时序、状态机 | MCU/FPGA/接口 | 真值表、触发器、状态机 |
| 信号与系统 | 时域/频域、卷积、傅里叶/拉普拉斯、采样 | 通信/控制/DSP | 正弦、频谱、采样定理 |
| C 语言 | 变量、控制、函数、数组、指针、内存 | 嵌入式/上位机 | 指针、结构体、位运算 |
| 单片机/嵌入式 | GPIO、定时器、中断、ADC、PWM、总线 | 嵌入式核心 | GPIO/ADC/PWM/中断 |
| 通信原理 | 调制、信道、噪声、编码、同步 | 通信核心 | AM/FM、QPSK、BER |
| 控制工程 | 反馈、稳定性、PID、状态空间 | 自动化/机器人 | 开环/闭环、PID |
| 微机原理/组成 | CPU、总线、存储、中断、接口 | 底层系统 | 冯·诺依曼、中断 |
| 电磁场/射频 | 传输线、天线、匹配、EMC | 射频/微电子 | 波长、阻抗、S11 |
| 传感器技术 | 物理量→电信号、标定、噪声 | 感知/嵌入式 | 分压、电桥、滤波 |

## 建议学习顺序（转专业前/后）

1. C 语言 + 电路分析：能算 LED 限流、能写 GPIO。
2. 数字电子 + 单片机：GPIO/ADC/PWM/中断/串口。
3. 模拟电子 + 传感器：运放/滤波/标定。
4. 信号与系统 + 通信原理：频谱/采样/调制。
5. 控制工程/射频/微机原理：按方向深入。

## 三个方向怎么选课

- **嵌入式**：C、单片机、数字电子、模拟电子、控制、RTOS、通信接口。
- **通信**：信号与系统、通信原理、数字信号处理、射频、FPGA/Verilog。
- **微电子**：模拟电子、数字电子、半导体物理、集成电路、版图/EDA（本科偏基础）。

## 面试怎么用

- 不要报菜名。选 2–3 门和你项目相关的课，讲“它解决什么问题 + 我学到哪”。
- 没学过的课，说“我知道它是基础，目前理解在概念层面”，不要装懂。
- 把课程和项目连起来：C → GPIO；数电 → 状态机；模电 → 传感器前端；信号 → 采样/滤波。

## 提醒

- 转专业前不需要自学完大二课程；先把 C/电路/数电/单片机中和你项目相关的部分打通。
- 课程地图是导航，不是待办清单；每学期只深入 1–2 门。
