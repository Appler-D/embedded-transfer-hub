# 转专业叙事：从化学 / 材料到电子信息工程

> 转专业不是“逃离原专业”，而是一次有证据、有规划的方向调整。
> 面试老师想确认三件事：你真的了解目标专业吗？你有能力补上基础吗？你会不会来了又走？

## 一句话结构

```text
我原来的专业训练让我具备 A（实验、数据、材料视角）；
我在 B（一次具体的电子/嵌入式经历）里确认了兴趣；
我已经开始补 C（电路、C 语言、单片机），并做了 D（项目/笔记）；
我希望在电子信息工程里继续做 E（嵌入式/自动化/硬件）。
```

把 A–E 换成你自己的事实。没有 D 就去造一个，不要编。

## 化学 / 材料背景能带走什么

| 原专业训练 | 对电子信息工程的迁移 |
| --- | --- |
| 实验设计与变量控制 | 调试电路、做对比实验、定位问题是电源/信号/代码 |
| 测量与误差分析 | 万用表/示波器读数、传感器标定、噪声与漂移 |
| 数据处理与图表 | 传感器数据分析、PID 调参、实验报告 |
| 材料/化学知识 | 半导体、电池、显示、封装、散热、可靠性 |
| 实验室安全规范 | 用电安全、焊接安全、静电防护 |
| 长期实验的耐心 | 硬件调试需要反复验证，不是一次编译就完 |

> 这张表是“可能的迁移”，不是自动获得。只写你真实上过/做过的；没有的删掉，不要编。

不要夸大“材料知识能直接做芯片”。更准确的说法是：

> 我了解材料层面的基本约束，比如电池的能量密度、封装的散热、焊点的可靠性；这让我在看硬件系统时多一个物理视角，但电路和编程仍需要系统补课。

## 需要补的短板

| 短板 | 先补什么 | 怎么证明 |
| --- | --- | --- |
| 电路 | 电压/电流/电阻、分压、RC、二极管/三极管/MOS | 能算 LED 限流、能解释去耦电容 |
| 信号 | 模拟/数字、采样、频率、噪声 | 能用示波器看 PWM/串口波形 |
| 编程 | C 基础、指针、结构体、位运算 | 能写 GPIO/ADC/串口程序 |
| 单片机 | GPIO、定时器、中断、ADC、PWM、总线 | 做出 2 个可演示项目 |
| 数学 | 复数、微积分、线性代数、傅里叶（逐步） | 不要求一次学完，知道用在哪 |
| 动手 | 面包板、万用表、焊接、读 datasheet | 有照片/视频/失败记录 |

## 60 秒自我介绍模板

```text
老师好，我是 XX 专业的学生。我申请转到电子信息工程，原因是……
我在原专业受过实验设计、测量和数据分析的训练，这些习惯能迁移到硬件调试。
为了确认兴趣，我做了……（一个具体项目），在这个过程中我学会了……
我也清楚自己的短板是电路和编程，所以我正在……（具体课程/项目/笔记）。
如果转入，我希望先补齐……，再在……方向深入。
```

不要只说“我感兴趣”。兴趣要用行为证明：你读了什么、做了什么、失败了什么、怎么修正。

## 常见追问

### “为什么转专业？”

错误：原专业不好、就业差、听说电子信息赚钱。
更好：

> 我在原专业的学习里逐渐发现自己更想解决“看得见、摸得着”的系统问题。一次……的经历让我确认了对电路和嵌入式方向的兴趣。我不是否定原专业，而是想把已有的实验能力放到更匹配的方向上。

### “你基础比别人差，怎么办？”

> 我确实起步晚。我已经把差距拆成电路、C 语言、单片机三块，并按周补。我的优势是实验习惯和自学能力；我不指望一学期追上，但我有具体的补课计划和可展示的进度。

### “你了解电子信息工程吗？”

不要只说“修电脑/玩单片机”。可以这样分：

> 它不只是某一个方向，至少包括电路与系统、信号与信息处理、通信、嵌入式、控制、电磁场与微波等。我现在接触最多的是嵌入式：用 MCU 采集传感器、做控制、和上位机/网络通信；这也是我目前最想深入的方向。

### “你最近在学什么？”

说一个具体概念 + 一个动手结果 + 一个还没解决的问题。例如：

> 我在学 ADC 采样和 PWM。我用一个电位器调 LED 亮度，发现读数有抖动，后来加了简单滤波。下一步想搞清采样率和滤波窗口的取舍。

### “如果来了发现不喜欢怎么办？”

> 我现在做的是小步验证：先做项目、再谈方向。如果深入后发现更适合信号或通信，我也会在电子信息工程内部调整；我不会把“转专业”当成终点。

## 不要说的话

- “原专业太坑了。”（否定过去，老师会担心你以后也否定这里。）
- “我什么都不会，但我会努力。”（只有态度，没有证据。）
- “嵌入式很简单，我看看就会。”（轻视专业。）
- “我自学了三个月，已经精通。”（过度承诺，追问就露馅。）
- “我主要是为了就业。”（可以谈现实，但不能只有这一句。）

## 证据清单

- [ ] 一个真正做完的小项目（代码 + 接线 + 照片/视频）
- [ ] 一本笔记/仓库，能看到你从不懂到懂的过程
- [ ] 一次失败与修正的记录
- [ ] 一个能说清的概念（ADC/PWM/中断/闭环，任选）
- [ ] 一个具体的补课计划
- [ ] 一个你能反问老师的好问题

## 反问老师的问题

- 如果转入，大一/大二的哪些课程最需要提前补？
- 学院有没有面向转专业学生的补修安排或学习小组？
- 本科生进实验室一般需要什么准备？
- 嵌入式方向在课程里通常从哪门课开始？

这些问题能说明你在认真规划，而不是只想“进来”。
