# 项目 2：传感器 + OLED

> 目标：读一个环境传感器，在 OLED 上显示，并通过串口输出。
> 难度 ★★；3–5 小时；成本约 50–100 元。

## BOM

| 数量 | 物料 | 备注 |
| --- | --- | --- |
| 1 | ESP32 或 Arduino Uno | 3.3V/5V 注意 |
| 1 | AHT20 / SHT31 温湿度 | I2C，地址 0x38 / 0x44 |
| 1 | SSD1306 OLED 128×64 | I2C，地址 0x3C 或 0x3D |
| — | 杜邦线/面包板 |  |

> 也可以用 DHT22（单总线），但 I2C 更适合练“总线 + 多设备”。

## 接线

| 模块 | 引脚 | 接到 |
| --- | --- | --- |
| 传感器 | VCC | 3.3V |
| 传感器 | GND | GND |
| 传感器 | SDA | GPIO 21 |
| 传感器 | SCL | GPIO 22 |
| OLED | VCC | 3.3V |
| OLED | GND | GND |
| OLED | SDA | GPIO 21 |
| OLED | SCL | GPIO 22 |

注意：ESP32 是 3.3V，不要把 5V 传感器直接接上；I2C 上拉通常模块自带。

## 步骤

1. 用 I2C 扫描示例确认地址（0x38/0x44/0x3C）。
2. 只读传感器，串口打印温湿度；确认数值合理。
3. 只点 OLED，显示 “Hello”；确认地址/方向。
4. 合并：读传感器 → 显示两行 → 每 2 秒刷新。
5. 加简单平均滤波（8 次），比较原始/滤波后的波动。
6. 记录：接线图、串口截图、OLED 照片、失败与修正。

## 代码思路（不贴整段，避免库版本坑）

- 库：AHT20 用 `Adafruit AHTX0`；SSD1306 用 `Adafruit SSD1306` + `Adafruit GFX`（Arduino/ESP32）。
- `setup()`：`Wire.begin(21,22)`；初始化传感器/OLED；失败就串口打印并停。
- `loop()`：读温度/湿度 → 平均 → `display.clearDisplay()` → 设置光标 → 打印 → `display.display()` → `delay(2000)`。
- 如果读数 `nan`：检查地址、供电、上拉、线长。

## 常见失败

| 现象 | 可能原因 |
| --- | --- |
| I2C 扫描不到 | 地址错、SDA/SCL 反、供电、模块坏 |
| OLED 花屏/不亮 | 地址 0x3C/0x3D、初始化参数、复位脚 |
| 读数不变/NaN | 传感器没初始化、地址错、供电不足 |
| 一接 OLED 就复位 | 供电/地线、I2C 上拉、线太长 |

## 面试三句话

1. 这是“感知 → 处理 → 显示”的最小系统：I2C 读传感器，MCU 处理，I2C 写 OLED。
2. 我处理了地址扫描、读数抖动（平均滤波）和接线错误。
3. 下一步可以加 Wi-Fi 上报，把数据送到电脑/手机。

## 安全

3.3V 低压；不要短路；OLED 不要长期显示静态高亮图案（烧屏）。
