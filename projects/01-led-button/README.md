# 项目 1：LED + 按钮

> 最小闭环：输入（按钮）→ 判断（去抖/状态）→ 输出（LED）→ 串口观察。
> 1–2 小时能做完，适合面试前快速拿一个“我真做过”的项目。

## 你会学到

- GPIO 输入/输出、上拉电阻。
- 按键机械抖动与软件去抖。
- 状态保持（按一下开，再按一下关）。
- 用串口观察程序行为。

## BOM

| 数量 | 物料 | 规格 | 备注 |
| --- | --- | --- | --- |
| 1 | 开发板 | Arduino Uno 或 ESP32 | 两者都可以 |
| 1 | LED | 红色/绿色，3mm/5mm | 注意长短脚 |
| 1 | 电阻 | 330Ω | LED 限流 |
| 1 | 按键 | 四脚轻触 | 两脚一组 |
| 1 | 面包板 + 杜邦线 |  |  |

## 接线

| 连接 | 说明 |
| --- | --- |
| LED 长脚（阳极）→ 330Ω → GPIO 13 | 电阻串联限流 |
| LED 短脚（阴极）→ GND | 极性不要反 |
| 按键一端 → GPIO 4 | 使用内部上拉 |
| 按键另一端 → GND | 按下读到 LOW |

注意：

- Arduino Uno 是 5V，ESP32 是 3.3V；不要给 ESP32 引脚加 5V。
- 用外部 LED，不要依赖板载 LED（不同板子引脚不同）。
- 四脚按键同一边的两脚通常内部相连；不确定就用万用表通断档确认。

## 代码

文件：[led_button.ino](led_button.ino)

核心逻辑：

1. 读按键，记录最后一次变化时间。
2. 如果 20ms 内没有新变化，认为状态稳定。
3. 稳定状态从 HIGH 变 LOW（按下）时，翻转 LED。
4. 串口打印当前状态。

## 预期现象

- 上电 LED 灭，串口打印 `LED + button ready`。
- 按一下 LED 亮，串口 `LED ON`；再按一下灭，`LED OFF`。
- 快速连按不会乱跳（去抖生效）。

## 测试清单

- [ ] 不按按钮时 LED 状态稳定
- [ ] 每按一次只翻转一次
- [ ] 串口波特率 115200，输出正常
- [ ] 拔掉按钮一端，LED 不会乱闪（上拉有效）
- [ ] 用万用表确认 LED 电流在 5–15mA 左右

## 常见失败

| 现象 | 可能原因 | 排查 |
| --- | --- | --- |
| LED 不亮 | 极性反、电阻太大、引脚写错 | 万用表测电压/通断；换方向 |
| 一按就多次翻转 | 没有去抖或去抖太短 | 增大到 20–50ms |
| 不按也乱跳 | 输入悬空 | 检查上拉/接线 |
| 串口乱码 | 波特率不匹配 | 统一 115200 |
| ESP32 一按就重启 | 按到启动 strapping 引脚或短路 | 换 GPIO4，检查接线 |

## 面试三句话

1. 这是一个输入→判断→输出的最小系统：按钮读 GPIO，程序去抖并维护状态，LED 输出。
2. 我用了 `INPUT_PULLUP` 和 20ms 去抖，避免机械抖动导致一次按下多次触发。
3. 我第一次做的时候 LED 不亮，后来发现是极性接反；从那以后我先用万用表确认再上电。
